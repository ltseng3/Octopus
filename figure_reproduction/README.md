# Research figure reproduction

The twelve figures in the expanded inference-diversity study can be redrawn exactly from the archived numerical inputs. This directory contains the original rendering scripts; the complete student archive includes `sources/`. The public source mirror omits recorded traces and frozen research artifacts pending redistribution review. Copy the complete `sources/` folder from the student bundle into this directory to use the full recipe. No upstream detector inference or GPU is needed to redraw the figures.

From the repository root:

```bash
python -m pip install -e '.[empirical_plot,empirical_download,test,yaml]'
python figure_reproduction/regenerate_figures.py
```

The wrapper creates `figure_reproduction/figures/`, verifies the bundled source hashes when available, runs the four scripts in order and checks that all twelve expected PDFs exist. It also runs the analytical and class-specific computations in those scripts. The extra disagreement/frame diagnostic is not one of the twelve manuscript figures. Use the recorded CSVs to verify the numerical results; exact PDF bytes can depend on versions and timestamps.

## Rerun the underlying experiments

Run from the simulator root, using the full student archive for the real 0007 trace and nine-scene reference counts. Use new output directories so the frozen source hashes remain intact. Use these full settings, not small toy settings, for the comparison.

```bash
# Fig 3: independent artifacts, exact analytical probabilities
python examples/reuse_toy.py --output outputs/partition_risk.csv

# Fig 4: nine-scene summary + 0007 paired analysis, from archived predictions
python scripts/run_cvc_figure_study.py \
  --output outputs/nine_scene --bootstrap-repetitions 20000 \
  --bootstrap-seed 20261119

# Fig 7, 10, 11, 12: three-observer synthetic / execution study
python scripts/run_three_agent_tradeoff_frontier.py \
  --output outputs/three_agent --frames 2000 --rois 2 \
  --online-frames 600 --seed 77109 --bootstrap 2000

# Fig 8: five-observer controlled dependence study
python scripts/run_f0_cvc_parameter_study.py \
  --output outputs/five_agent --frames 2000 --rois 2 \
  --seed 5701 --bootstrap 2500 --online-check-frames 180

# Fig 9: real 0007 recorded predictions; simulated costs
python scripts/run_e1_multiobjective.py \
  --output outputs/e1 --synthetic-events 3000 --bootstrap 3000 \
  --block-length 12 --bootstrap-seed 711910
```

Match the regenerated result files to their frozen inputs before changing any plotted data:

- `outputs/nine_scene/nine_scene_metrics.csv` -> `sources/nine_scene_metrics.csv`; compare `STUDY_REPORT.json` and its interval. The figure labels for the aggregate interval are annotated constants, so update them deliberately if a new dataset/statistic changes them.
- `outputs/three_agent/` -> the four corresponding same-named CSVs (`shock_and_policy_grid.csv`, `expert_calibration_grid.csv`, `deadline_reliability_energy_sweep.csv`, `roi_threshold_physical_cost_grid.csv`); check `PROVENANCE.json` and `offline_online_dag_crosscheck.csv`.
- `outputs/five_agent/lineage_correlation_sweep.csv` -> `sources/five_agent_lineage_sweep.csv`; `paired_frame_bootstrap_contrasts.csv` -> `five_agent_paired_bootstrap.csv`; `STUDY_PROVENANCE.json` -> `five_agent_provenance.json`.
- `outputs/e1/multiobjective_policy_metrics.csv` -> `sources/multiobjective_policy_metrics.csv`; compare `PROVENANCE.json`, energy profile and block bootstrap sensitivity CSVs.
- Figs 5/6 regenerate from the pinned 0007 trace with the label-only analyzer. Do not assume the 0007 gate equals OR on any other trace.

The frozen source files are checksummed. For experimental changes, make a **separate copy** of the figure directory, replace only the appropriate inputs with new, provenance-tracked outputs, update the numerical annotations and input manifest, and rerender. Never overwrite the archival inputs in place. `scripts/verify_cooperscene_mini_release.py` verifies the original full-release files only when using the complete student archive.

## Regenerate all recorded outcomes from upstream

On a networked machine with access to the pinned DMSTrack repository, run:

```bash
python scripts/prepare_dmstrack_v2v4real.py \
  --output outputs/v2v4real_full \
  --check empirical/v2v4real/sequence_counts.csv
```

The `--check` file is in the full student archive; omit it for a source-only clone until the trusted reference is available. The converter downloads the pinned public text files (no GPU), writes a combined `trace.jsonl`, `provenance.jsonl`, `source_manifest.json`, and `sequence_counts.csv`, and records the scenario. To change the diagnostic task, use `--threshold` and `--radius` in a separate output directory and omit `--check`. The fixed-grid task is generated alongside the balanced counts. Preserve scene identity. The current 0007 analyzer has an assertion about one specific trace: generalize the analyzer to each sequence and report the equality as a result, not an imposed condition.

Only the source code and constructed data are published in the public mirror. Nine-sequence full event-level traces still need regeneration; no new real sensor processing or three-vehicle results are claimed here. Do not confuse class-specific replay, synthetic parameters and measured hardware results.
